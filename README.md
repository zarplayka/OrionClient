# Orion Client

Клиентский Fabric-мод для Minecraft 26.3, Java 25

## Сборка

На Windows установите Java 25 и .NET SDK 8.0.421, затем выполните:

```powershell
./gradlew.bat build
```

Gradle Wrapper использует Gradle 9.6.0. Готовые JAR находятся в `build/libs/`.
Медиапомощники компилируются при сборке проекта и включаются в JAR готовыми.
На компьютере игрока компиляция не выполняется.

Для проверяемого выпуска запустите **Actions → Verified release build**.
Workflow сохраняет JAR, исходники медиапомощников и SHA-256 в артефакт
`orion-client-verified`. Проверка пересобирает исходники из самого JAR и
сравнивает результат с вложенными исполняемыми файлами.

Подробности для модерации и воспроизведения сборки:
[native/media/README.md](native/media/README.md).
